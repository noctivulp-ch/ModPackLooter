# Skills del proyecto

Copiadas de [anthropics/skills](https://github.com/anthropics/skills) (licencia
Apache-2.0, ver `LICENSE.txt` de cada carpeta) para trabajar el sitio generado:

- `frontend-design`: criterios para una interfaz intencional y humana, no de
  plantilla (tipografía, estructura, textos).
- `webapp-testing`: probar el sitio con Playwright (capturas, flujos, consola).

Se usan junto con `impeccable` (auditoría de UX y diseño) y respetando
Wulfenite UI ([ADR-0012](../../docs/decisiones/0012-sitio-con-wulfenite-ui.md)).
