## ModPackLooter 0.2.1 · servidores sin vueltas

Versión pequeña para que analizar un **servidor dedicado** funcione sin opciones extra.

### Cambios

**🖥️ Datos vanilla en cualquier servidor**
El `server.jar` muchas veces no es el jar de Mojang (es el lanzador del cargador o del host).
Ahora la app busca los datos donde cada uno los guarda:

| Servidor | Dónde |
|---|---|
| Oficial | `server.jar` (bundler) o `versions/<v>/server-<v>.jar` |
| Forge, NeoForge 1.20.1–1.21.1, Mohist, Arclight | `libraries/net/minecraft/server/…-extra.jar` |
| NeoForge (instaladores nuevos) | `libraries/net/minecraft/server/<v>/…` y `minecraft-server-patched` |
| Fabric, Quilt | `.fabric/server/`, `.quilt/server/` y `remappedJars/` |
| Paper, Purpur, Folia | `cache/mojang_<v>.jar`, `versions/<v>/` |

Y se acabó el aviso falso «el jar no contiene los datos de Minecraft» cuando los datos sí
estaban en otro lado.

**🌐 Nombres vanilla en español sin `--assets-dir`**
Los jars de servidor solo traen inglés. Ahora la app busca sola la carpeta `assets` de
**Prism** (también Flatpak, Windows y macOS), CurseForge y el launcher oficial. Si generas el
sitio en el mismo equipo donde juegas, basta con:

```bash
modpacklooter build /ruta/al/servidor -o sitio
```

Si el servidor está en otra máquina, sigue sirviendo `--assets-dir <carpeta assets>`.
